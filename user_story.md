# User Story

## Epic: Quản lý hệ thống bán hàng Laptop

### User Story 1

- As a Admin, I want to manage user accounts and assign roles so that the system is secure and each employee can access the right features.

### User Story 2

- As a Sales Staff, I want to create and process sales orders quickly so that I can serve customers in the store without delay.

### User Story 3

- As a Warehouse Manager, I want to monitor inventory levels and update stock movements so that I can prevent out-of-stock situations.

### User Story 4

- As an Accountant, I want to view financial reports and revenue summaries so that I can track business performance and manage cash flow.

### User Story 5

- As a Customer, I want to place online orders and track shipment status so that I can buy products conveniently and know when my order will arrive.

### User Story 6

- As a Customer, I want to apply vouchers and discounts during checkout so that I can save money on my purchase.

### User Story 7

- As an Admin, I want to manage products and upload product images so that customers and staff can see accurate product details.

### User Story 8

- As a Warehouse Manager, I want to receive low stock alerts so that I can restock products before they run out.

### User Story 9

- As a Sales Staff, I want to handle returns and refunds so that customers are satisfied and inventory is updated correctly.

### User Story 10

- As a Customer, I want to view my order history so that I can check previous purchases and track delivery progress.
